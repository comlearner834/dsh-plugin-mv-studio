# Completed example: 回家的路 / The Long Way Home

A 12-second, 1280×720, 24 fps painted-animation music video. All visuals are
drawn by code; the soundtrack is a deterministic synthesis, not a model
output.

## What is here

| Path | Contents |
|---|---|
| `output/long-way-home.mp4` | final H.264 + AAC, 12.00 s |
| `output/long-way-home.srt` | lyric sidecar generated from the LRC |
| `output/manifest.json` | checksums, source hash, renderer |
| `sheets/poster.jpg` | 1280×720 representative frame |
| `sheets/storyboard.jpg` | 3 keyframes × 3 shots |
| `sheets/review-*.jpg` | 8 fps draft review sheets |
| `sheets/final-*.jpg` | clean full-resolution final sheets |
| `reviews/*.json` | draft and final verdicts with notes |
| `project.json` | 3 shots, 4 s each, 96 frames per shot |
| `scenes/` | window, street, dawn |
| `lyrics/long-way-home.lrc` | 4 timed lines |
| `audio/long-way-home.mp3` | generated ambient cue |

## The three shots

1. **窗 / window** — dusk room, paper moon, window frame, curtain folds. The
   camera pushes in 18 px over 4 s. Lyric line 1 enters at 0.5 s.
2. **雨 / street** — rain, sodium lamps, receding houses, a figure under an
   umbrella. Camera pans 42 px. Lyric line 2 at 3.6 s.
3. **早班车 / dawn** — warm horizon, bus arriving, waiting figure, birds.
   Lyric lines 3–4 at 7.2 s and 10.0 s.

## Reproduce

```powershell
cd "D:\work\long-way-home"
npm install
node render.mjs check
node render.mjs storyboard
node render.mjs review --shot 01-window
# ... inspect and record verdicts for all three shots ...
```

This example does **not** ship `approval.json`: a full render still requires
the user's explicit local choice. To reproduce the finished file after the
draft reviews:

```powershell
node render.mjs approve --mode local --quote "用户原话"
node render.mjs final
# inspect sheets/final-*.jpg equivalents under build/final
node render.mjs final-verdict --shot 01-window --pass --notes "..." --sheet build/final/01-window/contact-sheet.jpg
# ... all three ...
node render.mjs final --encode
```

## Notes

- The soundtrack is generated by `tools/make-audio.mjs` (sine/triangle
  synthesis + delay + noise). It is not required for the skill; replace it
  with the user's song.
- The LRC is plain line-level LRC. Enhanced `<mm:ss.xx>` word tags are also
  supported; the engine wipes by line progress.
- The source hash in `output/manifest.json` matches the source files in this
  folder. Editing any scene, the LRC, the audio, or the engine invalidates it.
